# Build plan: Geographic Features deck

## Goal

An Anki deck of 132 physical features (126 places + 6 climate systems). 34 more are retired: all 10 passes and corridors, the 15 islands, and 9 of the 15 climate systems (the pressure belts, the East Asian and West African monsoons, the Canary, Benguela, Humboldt and Kuroshio currents, and the Bay of Bengal cyclones). This is research-independent.md minus the five excluded political/strategic rows. Each card shows a map with one place highlighted and its feature type ("Strait", "River"…) on the front, and its name on the back. Everything is generated by one command, with no manual steps per build.

## Pipeline

```
data/features.yaml ─┬─> make ids (mint missing uids via `ankc gen chunk`, written back into features.yaml)
geometry/*.geojson ─┤
vendor/ne @ sha     ┴─> resolve ─> render ─> deck/media/<sha256[:12]>.png ─> deckgen ─> deck/*.md ─> ankc check ─> ankc build ─> dist/*.apkg
```

- `make all` = `ids check-data render deck check build`.
- `deck/` is pure output, a function of `features.yaml` plus the renders. It's gitignored and nothing reads it back.

## `features.yaml`

```yaml
- id: nile
  uid: aB3xK9m2Qr             # Anki note GUID; minted once, never edited
  name: Nile
  alt_names: []
  type: River                 # shown on the front; one of 23 words, each in a family (see below)
  category: Rivers & Deltas   # category::<slug> tag; groups the PDF guide
  tier: 1
  style: line                 # area | line | point | strait | flow-current | flow-wind | band
  geometry:                   # list of parts, merged
    - {layer: rivers_lake_centerlines, select: {name: Nile, rivernum: 1}}
    - {layer: rivers_lake_centerlines, select: {name: White Nile}}
  expect: {bbox: [24, -4, 36, 32], length_km: [4500, 6800]}
- id: st-lawrence
  ...
  geometry:
    - {layer: rivers_lake_centerlines, select: {name: St. Lawrence, rivernum: 23}}
    - {layer: geography_marine_polys, select: {ne_id: 1159106939}}
- id: khyber-pass
  ...
  style: point
  geometry: [{file: khyber-pass.geojson}]
- id: some-feature
  retired: true               # keep the full entry; retire instead of deleting so the uid is never reused
```

**Selectors:**
- `ne_id` is the default.
- `{name, rivernum}` is used for rivers, which have no ids.
- `file` points at a hand-authored part.
- `feature` reuses another card's geometry; with `subtract: true` it cuts that card out (the Delta out of the Indo-Gangetic Plain). Prefer a reference over copying another card's selector or shape.

Wikidata is a reference field only, because the NE ids are sometimes wrong (Japan → Q17, shared Flores id).

Every selector must match exactly the expected rows, and `expect` (bbox, length or area range) is asserted. This catches wrong-river matches such as Pearl → Mississippi or Grande → 6 rivers.

**`expect` is a drift check, not a fact check.**
- A range brackets what the geometry measures now, about ±10%. It fails when a data update, a selector or a hand edit changes the shape noticeably.
- Where the published value is near enough, the range is widened to include it, and a comment gives the figure ("published 3,180 km").
- Where Natural Earth's generalised geometry can't reach the published value, the range stays around NE and a comment says how far off it is ("NE's line is ~20% short of the published 6,300 km"). The geometry is never stretched to match.
- Every area, band and flow feature has a size range. Climate features, which have no published size, get a range around the drawn shape.

## Type vocabulary

- The card shows one of 23 type words (`model.FeatureType`). See docs/adr/0001-type-vocabulary.md.
- Each word covers 3 or more cards, with four exceptions:
  - Isthmus tells the Isthmus of Kra apart from the Malay Peninsula, which contains it.
  - Valley and Sea route come from the user's own merges.
  - Cape has no honest merge.
- Pass, Corridor and Island stay in the vocabulary, but every card using them is retired.
- `qualifier` is used only for the season a climate map shows ("Wind system, July").
- Each word belongs to a coarse `family` (`model.FAMILY`):

| Family | Words |
|---|---|
| water body | Ocean, Sea, Lake |
| river | River |
| sea passage | Strait, Canal, Sea route |
| land passage | Pass, Corridor |
| relief | Mountain range, Plateau |
| lowland | Plain, Desert, Valley, Delta |
| region | Region |
| landmass | Peninsula, Isthmus, Cape |
| island | Island |
| climate | Ocean current, Wind system, Climate belt |

- The pair check compares families, not words.
- Area features in a land family (land passage, relief, lowland, region, landmass) are clipped to NE 10m land when resolved.
- Island is a family of its own and isn't clipped, because NE draws some island groups (the Spratlys) as a sea-area envelope.

## Data

- **Natural Earth v5.1.2,** pinned to commit `f1890d9f152c896d250a77557a5751a93d494776`. It's fetched with `gh api … contents/geojson/<f>?ref=<sha>`, because the direct CDNs are blocked on this machine.
  - Each file is checked against its sha256 and git blob sha, then moved into place in one step (write to a temp file, then rename).
  - CI uses `GITHUB_TOKEN`.
  - Layers: 10m regions/marine/rivers/lakes/points/elevation points/land/minor islands/admin_0, plus the 50m basemap.
- **Shaded relief:** NE `GRAY_50M_SR` (public domain), multiplied over land at 25–35%. It comes from a raster that isn't in the GitHub repo, so fetching it is a phase-1 risk to resolve.
- **Hand-authored geometry,** 53 files in `geometry/`. Every GeoJSON feature carries a provenance record (docs/adr/0002-provenance-classes.md):
  - `source` says what was done.
  - `method` is one of `ne-derived`, `pd-dataset`, `reference-coords` or `hand-drawn`.
  - `refs` lists the references.
  - Shapes drawn from Britannica's text (not its maps) are `hand-drawn` and say so in `source`.
  - The scripts behind the `pd-dataset` and derived shapes are in `tools/`, with dataset versions and access dates in `tools/README.md`.
- **The original hand-authoring list, about 35 features:**
  - Hormuz, Tiran, Kerch, Bashi, Lombok/Sunda, Bering, the Belts, GIUK, Northern Sea Route, Grand Canal
  - Passes and corridors (except Khyber and Hexi)
  - Fertile Crescent, Iranian Plateau, Pannonian Plain, Iberian/Italian/Sinai peninsulas, Arabian Desert, Levant, Indo-Gangetic Plain (Indus half)
  - Oder–Neisse, Pearl River
  - Gibraltar, Bab el-Mandeb, Luzon as strait shapes
  - All 15 climate systems (9 since retired)
- **Hand-authoring rule:** traced from public-domain references, with a `source` property. No OSM-derived files, because those would fall under ODbL share-alike.
- **Lakes that have changed over time:** the Aral Sea and Lake Chad are drawn as their present-day outlines. The Aral card also shows the 1960 shoreline as a dashed grey line (`frame.former`, a hand-drawn file), never highlighted.

## Rendering

- **Image:** 1600×900, quantized to an 8-bit palette, no letterbox (the ocean colour fills the background).
- **Filename:** `sha256(png)[:12].png`. It doesn't reveal the answer, and when a map is re-rendered the note text changes, so Anki picks up the new image.
- **Projections:** all maps are north-up with vertical meridians; cylindrical projections only (docs/adr/0003-projection-and-framing.md).
  - Regional frames: equirectangular in metres, central meridian and standard parallel at the frame centre. Fitted round the feature (or `frame.centre`), then redrawn centred on that frame and refitted.
  - World map (plate carrée, the same projection with standard parallel 0) for anything spanning more than about 10,000 km (oceans, global climate belts).
  - No frame shows past a pole. A polar band (the Arctic Ocean) gets a frame the globe's full width with the pole as its top edge.
- **Framing:**
  - The highlight fills 30–55% of the frame's long axis.
  - Every regional frame is at least 2,600 km wide, so recognisable coastlines are always in view. Small features are found by their ring (below).
  - Per-card `frame` options: `min_span_km` (wider only), `centre` (shared frames such as the Hindu Kush/Pamirs/Karakoram, Lake Chad with the Bight of Biafra), `admin1` (state borders; only the retired Cumberland Gap used it), `former` (the Aral's 1960 shore).
  - The nearest neighbouring feature of the same type must be at least 60 px from the highlight.
- **Basemap (unlabelled):**
  - Land: `#E9E4D8`, with relief multiplied on top.
  - Ocean and lakes: `#C3D5E2`.
  - Borders: `#8E887E`, 1 px; 1.5 px on Pass, Corridor and Lake frames under 3,000 km (Pass and Corridor cards are retired, so only Lakes use it now). Cut out of lakes and straits.
  - State/province borders (`frame.admin1`, NE 50m admin-1): 1 px, used only by the retired Cumberland Gap.
  - Coastline: `#7F8A93`, 1.2 px.
  - Major rivers (scalerank ≤ 4): 1 px `#9DB8CC`, above borders so a border river still shows.
  - 10m land for frames under 4,000 km.
- **Highlight:**
  - Always `#B2182B`, and the only saturated colour on the map.
  - `area`: 40% fill (30% at sea) plus a 2.5–3 px outline.
  - `line`: 5 px with a white casing.
  - `strait`: 6 px channel line with a casing. A polygon strait whose mean width (2·area/perimeter) is over 12 px is drawn as a sea instead: 30% fill and a 3 px outline. At the 2,600 km minimum the Bosporus, Dardanelles, Danish Straits and Magellan are lines; the English Channel, Korea, Taiwan, Luzon and Malacca are seas.
  - `point`: a 32 px hollow ring.
  - An area smaller than a 33 px disc (equal-area diameter; ~16 px on a 390 px phone) or under 50 px long also gets a ring, and so does a strait or line (a canal) under ~60 px long.
- **Climate:**
  - Currents: solid arrowed lines.
  - Winds: dashed 4.5 px lines with 20 px chevrons.
  - Bands: 30% fill with a dashed edge.
  - Seasonal systems are drawn for one season, which is named in the type word ("Monsoon, July").
- **Locator inset:** shown on regional frames under 8,000 km (wider ones show whole continents).
  - The same 160 × 80 px plate carrée world map on every card, centred on 0° and never re-centred, marking the frame as a `#333` box (1.25 px), or a 6 px dot when the box would be under 16 px or cross 180°. Nothing in it is red.
  - Bottom-left by default; it moves to another corner if it would overlap the highlight.
- Strokes above are for an 800 px-wide image; double them at 1600 px.
- **Incremental:** a stamp file per feature, keyed on its yaml entry, its geometry files, the vendor shas and the renderer version.

## Deck

- **Card:** `**<type>**<br>![](media/<hash>.png) ::: <name>`, with alternate names in brackets. The uid comes from `features.yaml`.
- **One deck,** `Geographic Features`, no subdecks (docs/adr/0004-flat-deck-and-study-order.md). Earlier builds used `Geographic Features::<Category>::Tier <n>`.
  - Every card is written, in study order, to one file, `deck/geographic-features.md`, beside the media.
  - Each card carries the footnote tags `tier::<n>`, `category::<slug>` and `id_<feature-id>`.
- **Study order** (`order.py`): tier 1, 2, 3. Within a tier, a parent comes before its children and categories are interleaved. Siblings the pair check finds near each other are kept 3 or more cards apart where possible. The order comes from the pair results that `check data` caches in `build/siblings.json`. ankc 0.5 numbers new cards in source order, and Anki keeps those positions on a first import.
- **Known Anki behaviour:** re-importing updates a note but doesn't move its card to another deck or change its new-card position.

## Checks (`make check`)

1. **Schema:** ids and uids unique, every uid present (`make build` refuses a missing uid), enums valid.
2. **Geometry:**
   - Every selector matches exactly the expected rows.
   - `expect` bbox and size ranges hold.
   - Part types fit the style.
   - Every river is one connected line after snapping gaps under 20 km, and reaches its mouth.
   - Every feature in `geometry/` has a `source`, a known `method` and non-empty `refs`. The check fails if `source` says "unverified" or "placeholder", in any case.
   - No Ocean or Sea has an interior hole of open water (not land) over 10,000 km². Such a hole means a neighbouring sea was left out of the union.
3. **Sibling pairs:** features within 300 km of each other or overlapping are compared by their highlights, drawn as on one map framing both. World-map features are only compared with each other.
   - **Fail** if the highlights are near-identical (IoU ≥ 0.8), or if one covers the other (≥ 90%) and both types are in the same family. An override can't clear the IoU rule.
   - **Nested** features from different families ("Delta" inside a "River" frame, a pass inside a range) are kept and reported as info.
   - **Override policy:** fix a same-family nesting in the data first. Subtract the inner card with `{feature: <id>, subtract: true}` when the outer shape shouldn't include it (Singapore out of the Malay Peninsula, still subtracted though Singapore is retired; the Delta out of the Indo-Gangetic Plain). Use `allow_nested: [{id, reason}]` on either feature only when the inner feature is a named part of the outer one and cutting it out would misdraw the outer shape. The current cases are Aegean/Mediterranean, Barents/Arctic, Levant/Fertile Crescent, Pontic–Caspian/Eurasian Steppe and Zagros/Iranian Plateau. Arabian Desert/Arabian Peninsula is a cross-family pair, so it only nests, but it is recorded too: its IoU of 0.79 sits just under the 0.8 limit. The reason must say why the cards still differ. `make check-data` prints every override.
   - **Flow lines** (currents and winds) must chain head-to-tail; a piece drawn backwards fails.
   - `make check-data` prints the failing and nested pairs.
   - `make pairs` writes every pair to `build/pairs.log`. It draws the flagged, nested, allowed and near-threshold ones (IoU ≥ 0.5 or cover ≥ 0.7) side by side in `build/pairs-NN.png`, 50 to a page.
   - **Rivers:** a river must end at its mouth. A true end of the merged line, meaning a source or mouth rather than a junction, must be within 5 km of the sea. Set `expect.mouth: lake` for rivers that end in a lake, or `none` for inland sinks.
4. **Renders:** every feature has exactly one render, and `render` clears stale files first.
5. **ankc:** `ankc --version` is 0.5.x and `ankc check --deck "Geographic Features"` passes. After the build, the `.apkg` has one note per non-retired feature, all in the one deck, each with all its tags, and the new-card positions follow the study order.

## Phases

1. **Skeleton.** Run the full chain end to end on about 10 features covering every style. Exit test: rename an id, rename a name, move a tier and `rm -rf deck/`, then confirm the uids still match. Also import into Anki to confirm the tier-move behaviour.
2. **Hardest-cluster style prototype.**
   - Clusters: Bosporus/Dardanelles/Kerch, Himalaya/Karakoram/Pamir/Hindu Kush/Tibet, Nile/Nile Delta, Canary Current/trade winds.
   - Run a colour-blindness simulation, then decide on the style.
3. **All NE-resolvable features,** with contact-sheet QA.
4. **Hand-authored geometry.**
5. **Climate systems.**
6. **CI (optional):** GitHub Actions runs `make check build` and attaches the `.apkg` to releases.

## Open decisions for the user

- **Merged rows that name two places:** "Strait of Magellan / Cape Horn", "Lombok & Sunda Straits", "Panama Canal (and Isthmus)". Default: split each into separate cards.
- **Borderline items** (kept by default):
  - Siliguri Corridor (border-defined; since retired with the other passes and corridors)
  - GIUK Gap (naval concept)
  - Karakoram Highway / Khunjerab Pass (a road; since retired)
  - Northern Sea Route (a shipping route)
- **Nile:** default is White Nile + main Nile, with the Blue Nile drawn as a context river.
- **Root deck name:** `Geographic Features`.
